GFV DATA

Laboratório de tecnologia e dados

Um caderno de experimentos pessoais em desenvolvimento web, análise de dados públicos e automação.

Sobre

O GFV Data é um projeto pessoal, sem fins comerciais. Aqui ficam experimentos de programação: protótipos, estudos e ferramentas pequenas, construídos para aprender e para tornar dados públicos mais fáceis de ler.

Não há venda de produtos ou serviços, publicidade, cadastro de usuários nem coleta de dados pessoais.

O que se faz aqui

  • Visualização de dados públicos: painéis e gráficos feitos a partir de bases abertas de órgãos oficiais.
  • Desenvolvimento web: sites estáticos, APIs leves e hospedagem em nuvem.
  • Automação: rotinas que coletam, tratam e publicam dados de forma reprodutível.
  • Aplicativos: protótipos de apps para uso pessoal.

As ferramentas usadas são, principalmente, Python, JavaScript, TypeScript e Kotlin. O código fica no GitHub, em github.com/gfvdata-web.
